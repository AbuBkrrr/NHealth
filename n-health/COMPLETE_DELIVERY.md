## 💾 How to Use

### Import Components
```typescript
import { Button, Card, Modal, Toast, BottomNav } from '@components';

<Button variant="primary" size="lg">
  Book Appointment
</Button>
```

### Use Services
```typescript
import { services } from '@services/ModuleServices';

// Patient module
await services.patient.trackVitals(patientId, vitalsData);
await services.patient.addAllergy(patientId, 'Penicillin');

// Doctor module
await services.doctor.createPrescription(doctorId, patientId, prescData);
await services.doctor.checkDrugInteractions(['Drug1', 'Drug2']);

// Payment module
await services.payment.processPayment(userId, 5000, 'card');
await services.payment.setupInstallmentPlan(userId, 50000, 12);

// Appointments
await services.appointments.bookAppointment({...});
await services.appointments.compareProviders([id1, id2]);
```

### Use Design Tokens
```typescript
import { tokens } from '@theme/tokens';

const buttonStyle = {
  padding: tokens.components.button.padding.base,
  backgroundColor: tokens.colors.primary[500],
  borderRadius: tokens.borderRadius.base,
  color: tokens.colors.text.inverse,
};
```
