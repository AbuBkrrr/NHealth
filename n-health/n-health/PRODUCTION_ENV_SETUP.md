# Production Environment Variables

## Quick Reference: Render Dashboard Values

### Backend (n-health-backend)

Copy these values into Render Dashboard → n-health-backend → Environment:

```
NODE_ENV=production
PORT=4000
CORS_ORIGIN=https://admin.nhealth.com.ng
PUBLIC_URL=https://api.nhealth.com.ng
JWT_EXPIRES_IN=7d
SENDGRID_API_KEY=[YOUR_SENDGRID_KEY]
SENDGRID_FROM_EMAIL=noreply@nhealth.com.ng
```

**Notes:**
- `JWT_SECRET`: Auto-generated by Render Blueprint ✅ (do not override)
- `DATABASE_URL`: Auto-injected by Render from PostgreSQL service ✅ (do not override)
- `SENDGRID_API_KEY`: Get from https://sendgrid.com/settings/api_keys (see Step 6 of deployment guide)

---

### Admin Web (n-health-admin-web)

```
VITE_API_URL=https://api.nhealth.com.ng/api
```

---

### Mobile App (.env file)

```
EXPO_PUBLIC_API_URL=https://api.nhealth.com.ng/api
```

---

## Security Notes

1. **Never commit `.env` files** — all secrets are in Render dashboard
2. **JWT_SECRET is auto-generated** — use Render's value, it's already secure
3. **CORS_ORIGIN restricted** — only `admin.nhealth.com.ng` can call the API
4. **PUBLIC_URL must be HTTPS** — required for mobile app SSL validation
5. **SendGrid key** — keep private; only add to Render environment

## Email Configuration

**SendGrid Setup:**
1. Create account: https://sendgrid.com
2. Verify sender domain: `noreply@nhealth.com.ng`
   - Add TXT record to your DNS (SendGrid will provide)
   - Wait 5-10 min for verification
3. Create API key (Full Access)
4. Add `SENDGRID_API_KEY` to Render backend environment
5. Set `SENDGRID_FROM_EMAIL=noreply@nhealth.com.ng`

**Used for:**
- Payment confirmations
- Order updates  
- Appointment reminders
- Admin notifications

## Deployment Workflow

1. Push code to GitHub
2. Render auto-builds from Blueprint
3. Environment variables from Render dashboard (override `render.yaml` defaults)
4. Services deploy in order: Database → Backend → Admin-web
5. Manual Deploy needed only for env var changes

## Troubleshooting Environment Issues

**"Backend can't connect to database"**
- Check: Dashboard → n-health-backend → Logs
- Verify: `DATABASE_URL` exists and is correct (Render auto-sets this)
- Render uses: `postgresql://nhealth:nhealth@n-health-db:5432/nhealth?schema=public`

**"Admin page blank / can't reach backend"**
- Check: Browser F12 Console for CORS/network errors
- Verify: `VITE_API_URL=https://api.nhealth.com.ng/api` (no trailing slash on domain)
- Rebuild admin-web after changing VITE_API_URL

**"Mobile app won't connect"**
- Verify: Mobile `.env` has `EXPO_PUBLIC_API_URL=https://api.nhealth.com.ng/api`
- Rebuild and redeploy via EAS
