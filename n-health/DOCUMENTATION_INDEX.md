## 💡 TROUBLESHOOTING

**Q: App not loading?**
A: Clear browser cache (Ctrl+Shift+Del), then reload

**Q: Login not working?**
A: Verify email format, check internet connection

**Q: Signup shows error?**
A: Ensure password has 8+ chars, 1 uppercase, 1 lowercase, 1 number

**Q: Dashboard not responsive?**
A: Open DevTools (F12), toggle device toolbar, select iPhone 12

**Q: Tabs not changing?**
A: Refresh page, try different browser

**Q: Performance slow?**
A: Check internet speed, try incognito mode
