QUICK START
================================================================================

1. READ ROOT README
   → cat README.md
   → git clone https://github.com/AbuBkrrr/NHealth.git
   → cd n-health

2. READ DOCUMENTATION
   → cd docs/
   → Start with INDEX.md or README.md
   → Check DEPLOYMENT_AND_BUILD_COMPLETION_GUIDE.md for deployment

3. LOCAL DEVELOPMENT
   → Backend:   cd backend && npm install && npm run dev
   → Frontend:  cd admin-web && npm install && npm run dev
   → Desktop:   cd backend && npm run electron

4. DEPLOYMENT
   → Backend: git push origin main (Render auto-deploys)
   → Frontend: cd admin-web && vercel --prod
   → See docs/DEPLOYMENT_AND_BUILD_COMPLETION_GUIDE.md for details
