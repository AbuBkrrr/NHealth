### **Local Development**

**Backend:**
```bash
cd backend
npm install
npm run db:migrate
npm run dev
# Server: http://localhost:4000
```

**Frontend:**
```bash
cd admin-web
npm install
npm run dev
# App: http://localhost:5173
```

**Desktop App:**
```bash
cd backend
npm run electron
# Builds to .exe (Windows), .dmg (Mac), .AppImage (Linux)
```
