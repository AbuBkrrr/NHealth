# Provider flyers (QR code to the provider's page)

Every provider gets a flyer made by N-Health. Customers scan its QR code and land on that provider's N-Health page, where they can book, order or request care.

**Who gets one:** doctors, nurses, pharmacies, diagnostic centers, ambulance services and hospitals/clinics.

**Where:** the provider's Home → **Your N-Health flyer** → **Get my flyer** (`/flyer`).

## What the flyer shows
- the N-Health logo;
- the provider's name and type, address, and a ✓ Verified tick once approved;
- up to 5 services, which depend on the provider (for example "Order medicines online" and "Home delivery" for pharmacies; the first tests in the catalogue for diagnostic centers);
- a large QR code with the N-Health logo in the middle, plus "Scan to book / order medicines / book a test…";
- "Free on N-Health • www.nhealth.com.ng".

## Choices
- **Sizes:**
  - Poster: A5 (prints well on A4 too).
  - Square: WhatsApp and Instagram posts.
  - Status / story: 1080×1920.
- **Colours:** N-Health blue, the provider's own colour, or dark.
- **Download** a PNG, **Share** it (straight into WhatsApp and other apps on phones), or **Print** it.
- **Copy** the page link, or send it on WhatsApp.

## When someone scans it
1. The code opens `https://www.nhealth.com.ng/p/<provider>?ref=<provider's invite code>&src=flyer`.
2. **Signed out:** they see the provider's public page:
   - name, type, rating, address, hours and services;
   - a button such as **Order medicines on N-Health** that leads to sign-up, with the provider's invite code filled in.
   After signing up they go straight to the provider's page in the app.
3. **Already signed in:** they go directly to the provider's page in the app, where they can book, order or message.
4. **Invite reward:** a new customer who joins through the flyer is counted as the provider's invite, so the provider also earns the invite coin.

## Scan counts
The flyer screen shows:
- scans (all time and last 30 days);
- how many different people opened the page;
- how many people joined through the provider's link.

A phone is counted once per hour. No names or contact details are recorded; the count uses a random ID kept by the browser.

## What is public
The public page shows only business details:
- name, type, services, address, hours, rating and verified status.

It never shows phone numbers, email, the invite code or any patient data. Patients don't have public pages.
