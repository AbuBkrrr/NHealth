## ⚡ Quick Start (30 minutes total)

### 1️⃣ Deploy via Render Blueprint (5 min)
```
1. Go to https://render.com
2. Select workspace: tea-d995gq28qa3s73eb4ing
3. Click [+ New] → [Blueprint]
4. Connect: AbuBkrrr/NHealth
5. Click [Apply]
→ Wait 3-5 min for services to show "Live"
```

### 2️⃣ Configure Environment Variables (3 min)
```
Render Dashboard → n-health-backend → Environment
Add:
  NODE_ENV = production
  CORS_ORIGIN = https://admin.nhealth.com.ng
  PUBLIC_URL = https://api.nhealth.com.ng
  [SENDGRID variables if using email]
→ Manual Deploy
```

### 3️⃣ Configure Admin-Web (2 min)
```
Render Dashboard → n-health-admin-web → Environment
Update:
  VITE_API_URL = https://api.nhealth.com.ng/api
→ Manual Deploy
```

### 4️⃣ Initialize Database (2 min)
```
Render Dashboard → n-health-backend → Shell
npx prisma migrate deploy
npm run prisma:seed
```

### 5️⃣ Configure DNS (3 min)
```
At your DNS provider (GoDaddy, Namecheap, etc.):

Add CNAME:
  api.nhealth.com.ng → [Render CNAME from backend]
  admin.nhealth.com.ng → [Render CNAME from admin-web]

Wait 5-10 min for propagation
```

### 6️⃣ Verify & Test (5 min)
```bash
# Health check
curl https://api.nhealth.com.ng/health
# Expected: {"status":"ok"}

# Admin login
https://admin.nhealth.com.ng
# Login: superadmin@demo.com / password123
```

✅ **You're live!**

## 🆘 Something Went Wrong?

### Troubleshooting Flow

**Q: Services not showing "Live"**
→ Check: Render dashboard Logs tab
→ Look for: Build errors, missing dependencies

**Q: Backend won't start**
→ Check: `DATABASE_URL` exists in environment
→ Check: Port 4000 is available

**Q: Admin page blank**
→ Browser F12 Console → look for CORS errors
→ Check: `VITE_API_URL` is correct

**Q: DNS not resolving**
→ Wait 10-15 minutes
→ Verify CNAME records added correctly
→ Test: `nslookup api.nhealth.com.ng`

**Q: Mobile app can't connect**
→ Update: `mobile/.env` with correct API URL
→ Rebuild via Expo

**More troubleshooting**: See `DEPLOYMENT_GUIDE_NHEALTH.md` → Troubleshooting section
