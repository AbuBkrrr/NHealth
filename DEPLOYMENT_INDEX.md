## 🔑 Critical Environment Variables

**Auto-Generated by Render (DO NOT CHANGE):**
- `JWT_SECRET` — Auto-generated
- `DATABASE_URL` — Auto-injected from PostgreSQL

**You Must Set:**
- `NODE_ENV` = `production`
- `CORS_ORIGIN` = `https://admin.nhealth.com.ng`
- `PUBLIC_URL` = `https://api.nhealth.com.ng`
- `VITE_API_URL` = `https://api.nhealth.com.ng/api` (admin-web)

**Optional (Email):**
- `SENDGRID_API_KEY` = (from SendGrid)
- `SENDGRID_FROM_EMAIL` = `noreply@nhealth.com.ng`

📖 **Full reference**: `PRODUCTION_ENV_SETUP.md`

## 🌐 DNS Records Required

Add these at your DNS provider:

```
Subdomain: api.nhealth.com.ng
Type: CNAME
Value: [Render CNAME from backend service]

Subdomain: admin.nhealth.com.ng
Type: CNAME
Value: [Render CNAME from admin-web service]

(Optional) Email verification TXT records from SendGrid
```
